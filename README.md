**데스 스타(Death Star)**는 멋진 터미널 애니메이션으로, 단순하고 맞춤 설정이 가능하지만 코딩 프로젝트를 시연할 때 차별점을 만들어 줍니다.

> [!NOTE]
> 전체 코드는 셸 스크립트를 사용하여 **아치 리눅스(Arch Linux)** 기반으로 제작되었으므로 **리눅스/맥**을 사용하거나 **WSL**을 사용해야 합니다. :: 코드를 실행하기 전에 권한을 부여하는 것을 잊지 마세요!
